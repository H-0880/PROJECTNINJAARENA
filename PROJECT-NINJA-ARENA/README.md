# PROJECT NINJA ARENA (PNA)

Original 3D arena-action game for PC and consoles, targeting Unreal Engine 5.8.

## Current milestone: PNA 0.2 — advanced movement (builds on 0.1)
This repository is a source/documentation scaffold. It is **not yet a generated Unreal project**:
the `.uproject`, engine-generated targets, project-specific module files and asset registry must be created by Unreal Engine 5.8 on a machine with the engine installed.

### Design pillars
- Responsive third-person movement and camera.
- Arena combat with readable hit windows, combos, blocking and evasion.
- Character-specific abilities and resource management.
- Optional racing and adventure modes built as separate game-mode modules.
- Multiplayer architecture designed around server authority.

### Target hardware
Development baseline: Intel Core i5 11th gen, Intel Iris Xe, 12 GB RAM.
Use small test maps, low scalability, limited dynamic lights and restrained VFX.
This is a development constraint, not the final visual target.

## Repository layout
- `Source/ProjectNinjaArena/` — Unreal C++ module scaffold.
- `Config/` — conservative scalability defaults; review in-engine.
- `Documentation/` — architecture, controls, combat and build notes.
- `Content/` — Unreal-managed assets (add through the editor).
- `.gitignore` — excludes generated/intermediate engine files.

## Create the actual UE 5.8 project
1. Install Unreal Engine 5.8 and compatible MSVC C++ Build Tools + Windows SDK.
2. In Unreal: Games → Third Person → C++ → Desktop → Scalable.
3. Project name: `PROJECT_NINJA_ARENA`.
4. Create it in a temporary folder, close the editor, then merge this repository's `Source/`, `Config/`, `Documentation/` and `.gitignore` into the generated project. Keep the `.uproject`, `*.Target.cs`, module Build.cs and module entry point generated by Unreal unless deliberately reconciling them.
5. Regenerate project files and compile the Development Editor target.
6. Open the project and run the Third Person template before replacing its character.

## Current code status
The movement component and character class are starter implementation examples. They require integration into the engine-generated module, input assets assigned in a Blueprint child, compilation and in-editor testing. No successful Unreal build is claimed yet.
