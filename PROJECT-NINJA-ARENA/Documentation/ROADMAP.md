# Development Roadmap

| Milestone | Deliverable | Exit criteria |
|---|---|---|
| 0.1 | UE project + movement | Compiles; move/look/jump/sprint/dash verified |
| 0.2 | Movement polish | Dodge, lock-on prototype, camera tuning |
| 0.3 | Combat | Hit windows, damage, guard, combo state |
| 0.4 | Abilities | Resource, cooldown and ability data |
| 0.5 | Training arena | Dummy, reset, combat telemetry |
| 0.6 | Multiplayer prototype | Server-authoritative 1v1 test |
| 0.7+ | Additional modes | Racing and Adventure prototypes |

Do not start multiple high-risk systems before the current milestone passes its exit criteria.
